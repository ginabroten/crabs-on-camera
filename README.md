# Crabs on camera

Code and pipeline for detecting brown crabs (*Cancer pagurus*) in underwater video, developed from the methods in my master's thesis. The repository is split into two: `create-a-crab detector` which follows the workflow utilized to create a YOLOv8 object detection model to detect brown crab insitu BRUVs, wheras `use-a-crab-detector` allows for application of either the pretrained crab detector developed in the thesis, or to apply another model as well as to interpret the predicted data. 

**Documentation:** [ginabroten.github.io/crabs-on-camera](https://ginabroten.github.io/crabs-on-camera/) - background, prerequisites, and a walkthrough of each script.

**Thesis:** Brøten, Gina. 2026. *Crabs on camera: Improving the monitoring of the brown crab (Cancer pagurus) with machine learning and Baited Remote Underwater Video (BRUV)*. Master's thesis, University of Bergen. https://hdl.handle.net/11250/5537346
